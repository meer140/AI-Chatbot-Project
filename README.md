# AI Chatbot Project

A modern, responsive AI-powered chatbot application built with React and Vite for fast development and optimal performance.

**Live Demo:** [https://ai-chatbot-project-kappa.vercel.app](https://ai-chatbot-project-kappa.vercel.app)

---

## 🚀 Features

- **Fast Development**: Powered by Vite with Hot Module Replacement (HMR)
- **Modern React**: Built with React 19 for the latest features and performance improvements
- **Type Safe**: Full TypeScript support with type-aware ESLint rules
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Production Ready**: Lightweight and optimized build configuration
- **Date Handling**: Integrated with dayjs for reliable date/time management

---

## 📋 Prerequisites

Before getting started, ensure you have the following installed:

- **Node.js** (v18.0.0 or higher)
- **npm** (v9.0.0 or higher) or **yarn**

---

## 🛠️ Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/meer140/AI-Chatbot-Project.git
   cd AI-Chatbot-Project
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

---

## 📖 Usage

### Development

Start the development server with hot module replacement:

```bash
npm run dev
```

The application will be available at `http://localhost:5173` (default Vite port).

### Building for Production

Create an optimized production build:

```bash
npm run build
```

### Preview Production Build

Preview the production build locally:

```bash
npm run preview
```

### Linting

Run ESLint to check code quality:

```bash
npm run lint
```

## 📦 Dependencies

### Core Dependencies

- **react** (^19.1.0) - UI library
- **react-dom** (^19.1.0) - React DOM utilities
- **dayjs** (^1.11.20) - Lightweight date/time library

### Development Dependencies

- **vite** (^6.3.5) - Build tool and dev server
- **@vitejs/plugin-react** (^4.4.1) - React plugin for Vite
- **eslint** (^9.25.0) - Code quality tool
- **eslint-plugin-react-hooks** (^5.2.0) - React hooks linting
- **eslint-plugin-react-refresh** (^0.4.19) - React refresh linting
- **@types/react** (^19.1.2) - TypeScript types for React
- **@types/react-dom** (^19.1.2) - TypeScript types for React DOM

---

## 🔧 Configuration

### Vite Configuration

Vite is configured to use the `@vitejs/plugin-react` plugin for optimal React development experience with Fast Refresh support.

### ESLint Configuration

The project uses ESLint with the following plugins:
- React Hooks rules
- React Refresh rules

For type-aware linting in production, consider enabling TypeScript-aware rules as described in the [Vite template documentation](https://github.com/vitejs/vite/tree/main/packages/create-vite).
